# Counter SU

Консольный счётчик на Java 25 LTS и Maven. Команды: `/inc`, `/reset`, `/stop`.

```sh
./mvnw clean verify
java -jar target/counter-su-1.0.0-SNAPSHOT.jar
# Другой файл состояния:
java -jar target/counter-su-1.0.0-SNAPSHOT.jar data/counter.txt
```

В Windows используйте `mvnw.cmd`. Нужен JDK 25; Maven загрузит Wrapper.
Значение сохраняется после каждой успешной команды и при завершении ввода (EOF).
Формат прежний: целое число в `out.txt`. Пустой/отсутствующий файл означает 0;
повреждённый файл вызывает понятную ошибку и не перезаписывается.
Переполнение int не приводит к отрицательному значению.

Состояние экземпляра заменило static-поле. Ввод, вывод и хранение разделены;
дублирующая реализация BestPractice удалена. Запись идёт через временный файл
и атомарную замену, если файловая система её поддерживает.
Приложение рассчитано на один процесс на файл: межпроцессной блокировки нет.
Набор тестов проверяет команды, EOF, перезапуск, ошибки хранения и переполнение.
