# Counter SU

Небольшой консольный счётчик на **Java 25** и **Maven**. Значение сохраняется
между запусками. В рабочем коде нет сторонних библиотек; для тестов используется JUnit.

## Сборка и запуск

Нужен **JDK 25**. Maven Wrapper загрузит Maven автоматически; при первой сборке
нужен интернет. Preview-функции не используются.

```sh
java --version
./mvnw clean verify
java -jar target/counter-su-1.0.0-SNAPSHOT.jar
```

Другой файл состояния и справка запуска:

```sh
java -jar target/counter-su-1.0.0-SNAPSHOT.jar data/counter.txt
java -jar target/counter-su-1.0.0-SNAPSHOT.jar --help
```

В Windows вместо `./mvnw` используйте `mvnw.cmd`.
В IntelliJ IDEA откройте `pom.xml` как Maven-проект, выберите JDK 25 для проекта
и Maven Runner, затем запустите `CounterApp`. Рабочий каталог определяет,
где будет находиться `out.txt`. Если IDEA не распознаёт нестатический `main`,
нужна версия IDE с поддержкой Java 25; запуск собранного JAR от IDE не зависит.

## Команды

| Команда | Действие |
| --- | --- |
| `/inc` | Увеличить значение на 1 и сохранить |
| `/reset` | Установить 0 и сохранить |
| `/value` | Показать текущее значение |
| `/help` | Показать справку |
| `/stop` | Сохранить и завершить работу |

Пробелы вокруг команд игнорируются, регистр имеет значение. Конец ввода
(Ctrl+D на macOS/Linux) работает как `/stop`. Неизвестная команда не меняет счётчик.
Сообщения приложения и поясняющие комментарии — на русском языке.

## Устройство проекта

Все классы находятся в небольшом пакете `aav`: для такого приложения
дополнительные слои и фреймворки не нужны.

| Класс | Ответственность |
| --- | --- |
| `Counter` | Неизменяемое значение (`record`) и увеличение с проверкой переполнения |
| `Command` | Разбор текста в типизированную команду (`enum` и `switch`) |
| `CounterRepository` | Контракт загрузки и сохранения |
| `CounterStore` | Реализация хранения в файле UTF-8 |
| `CounterProcessor` | Обработка команд одной сессии через переданные потоки |
| `CounterApp` | Аргументы запуска, подключение зависимостей и коды завершения |

Поток выполнения: `CounterApp` → `CounterProcessor` → `CounterRepository`.
Консоль не знает, как именно записывается файл. В тестах вместо диска можно
подставить хранилище в памяти или хранилище, которое сообщает об ошибке.

Из возможностей **именно Java 25** используется нестатический `main(String[] args)`
([JEP 512](https://openjdk.org/jeps/512)). `record`, выражения `switch`, текстовые блоки
и `var` появились раньше и также применяются там, где упрощают код.
Обычные именованные классы сохранены для понятной структуры Maven-проекта.

## Сохранность данных и ошибки

- Формат совместим с прежним проектом: одно число `int` в `out.txt`.
  Отсутствующий или пустой файл означает 0. Старые отрицательные значения поддерживаются.
- Повреждённое или выходящее за диапазон `int` число вызывает ошибку;
  такой файл не перезаписывается.
- При достижении `2147483647` увеличение отклоняется; можно выполнить `/reset`.
- Новое значение сначала записывается, и только затем выводится сообщение об успехе.
- Запись выполняется во временный файл в том же каталоге с последующей атомарной
  заменой. Если файловая система её не поддерживает, используется обычная замена.
  Это не гарантия сохранности при отключении питания: принудительный сброс на диск не выполняется.
- Ошибка чтения, записи или вывода завершает приложение с кодом `1`.
  Ошибка аргументов или синтаксиса пути — с кодом `2`; успешное завершение — `0`.
- **Один файл предназначен для одного запущенного экземпляра программы.**
  Межпроцессной блокировки нет; параллельные запуски могут перезаписать результаты друг друга.

## Проверки

```sh
./mvnw clean verify
```

Тесты проверяют команды, EOF, перезапуск, неизменяемость, переполнение,
повреждённые файлы, вложенные каталоги, ошибки хранилища, ввода и вывода,
аргументы командной строки. GitHub Actions также запускает собранный JAR.

При рефакторинге `CounterHolder` заменён на `Counter`, а методы хранилища принимают
и возвращают `Counter`. Это изменение Java API; формат файлов и прежние три команды сохранены.
